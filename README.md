# VR OI 考场 · 大战保安

> 你以为是来拿满分的？真正的主线，是打穿 500 名保安，走出考场。

**vr-oi-simulator** 是一款以 OI（信息学奥林匹克竞赛）考场为舞台的第一人称 3D 网页游戏。
监考、电脑、草稿纸和四小时倒计时构成了看似正常的赛场；打倒监考后，游戏才进入真正的主线：
用走位、跳跃和扇形扫拳，应对不断增援、包抄和突进的保安，直至击倒全部 **500 人**，走进终局的白光大门。

**大战保安是主线，写代码是支线。** 你也可以安静答题、干扰同学、举手找老师，或去洗手间，体验不同的考场结局。

## 游戏亮点

- **500 人战斗主线**：从最初的两名保安，到更大规模的增援与多耐久敌人；已出场名额有限，不是无限刷怪。
- **第一人称近战**：扇形扫拳可同时命中多个目标，配合疾走、跳跃、击退和受击无敌期周旋。
- **有压迫感的敌人**：保安会分散合围、斜向包抄、近距离突进；越到后期，耐久和速度越高。
- **越打越紧张**：灯光压暗、暗红雾色、心跳、镜头抖动和拖影随战况变化；击中角色会产生物理碎块。
- **通报与选择**：保安通报触发慢放，你可以选择配合，也可以嘴硬换来更多增援。
- **可以接着打**：自动保存血量、击倒数、存活敌人、待到场增援和开门状态，刷新后可继续。
- **打开即玩**：原生 JavaScript + Three.js，无后端、无构建步骤，无需安装 npm 依赖。

> 名称中的“VR”指沉浸式第一人称体验；当前版本使用键盘和鼠标操作，未实现 VR 头显 / WebXR 支持。
> 游戏中的人物、纪律处理和暴力情节均为虚构娱乐设定。

## 快速开始

```sh
git clone https://github.com/sun2snow/vr-oi-simulator.git
cd vr-oi-simulator
```

使用支持 WebGL 的桌面浏览器打开 `index.html`，点击 **“进入考场”** 即可开始。
也可以在 GitHub 下载仓库 ZIP，解压后打开该文件。

- **推荐环境**：桌面版 Chrome / Edge / Firefox，配合键盘与鼠标；当前没有触屏操作方案。
- **网络要求**：需访问 `cdn.jsdelivr.net` 加载 Three.js；失败时页面会给出提示。
  如需离线运行，可将对应版本的 Three.js（`0.128.0`）下载到本地，并修改 `index.html` 的脚本路径。
- **鼠标锁定**：进入考场后鼠标用于转动视角；锁定失败时点击场景重试。
- **舒适度设置**：可调整鼠标灵敏度、视角平滑、音量和时间流速，也可关闭镜头晃动。

### 第一次怎么玩

1. 进入考场，熟悉 WASD 移动和鼠标转向。
2. 靠近监考，正面对准后出拳，触发保安战并亮出 **3 格血条**。
3. 用疾走和跳跃保持距离，找准角度扫拳；多耐久保安不会一拳倒下。
4. 留意 HUD 的击倒数与场上保安数，处理增援和通报。
5. 击倒 **500 / 500** 后，走到白光门前按 **E**，完成主线「无人能挡」。

考试倒计时仍是本局的时间限制：默认 **15 倍速**，四小时虚拟时间约为 **16 分钟现实时间**。
可在开始界面或设置中调整倍率；打开设置不会暂停考试，违纪处罚也可能缩短剩余时间。

## 操作说明

| 操作 | 按键 |
| --- | --- |
| 移动 / 转向 | `W A S D` / 鼠标 |
| 疾走 / 跳跃 | `Shift` / `空格` |
| 场景交互 / 出拳 | 鼠标左键或 `E`，有可攻击目标时优先攻击 |
| 干扰同学 | 对准目标按 `F` |
| 举手呼叫监考 | `H` |
| 选择弹窗选项 | 注视按钮 1 秒、对准后按 `E`，或按对应数字键 `1–9` |
| 离开电脑、草稿纸等面板 | `Esc` |
| 释放鼠标 / 打开设置 | 世界视图下按 `Esc` |

## 答题与其他支线

每局随机抽取 **4 道题**，名义满分 **400 分**。电脑里有题面、C++ 编辑区、语法高亮和模拟评测；
此外还有草稿纸手写、同学互动、监考对话与洗手间流程。

**这不是在线评测系统。** 当前评测器不会编译或执行 C++，而是按关键字、代码长度、结构等规则生成确定性分数。
它服务于游戏体验，不能用来验证算法正确性或作为真实比赛成绩。

## 目录结构

```
index.html            页面外壳：head / body 标记 / 脚本加载顺序
assets/
  css/main.css        全部样式（原 index.html 内联 <style>）
  keywords.js         评分用 C++ 关键字表（静态数据）
  problems/_pool.js   题库注册表 PROBLEM_DATA + 起始代码模板（须最先加载）
  problems/P*.js      每题一个文件，格式为 PROBLEM_DATA.push({ ... })
js/
  judge.js            评测评分逻辑
  npc-gen.js          NPC 代码生成器（确定性）
  problems.js         题库逻辑：按 id 索引 / 每局抽 4 题
  core.js             工具函数 / 全局状态 / 几何材质缓存 / 音频 / DOM 引用 / 视角设置
  dialog3d.js          3D 悬浮弹窗：无遮罩、球面跟随、惯性、canvas 按钮拾取
  feedback.js         Toast 提示与成就解锁
  hp.js               玩家血条（监考倒台后显示）与受击反馈
  world.js            考场场景：房间 / 桌椅 / 显示器 / 人物 / 保安
  interact.js         准星交互判定（交互 / 干扰 / 攻击）
  combat.js           殴打老师 / 保安 AI / 全员收尾
  debris.js           击中爆散：形状感知的刚体物理（与地板/墙壁碰撞）
  npc.js              屏蔽词机制与选手 NPC 行为
  teacher.js          监考老师：警告 / 惩罚 / 举手对话
  corridor.js         走廊往返与洗手间流程
  ide.js              IDE 面板 / 语法高亮 / 提交评测
  paper.js            草稿纸手写板
  look.js             FPS 视角 / 指针锁定 / 玩家移动 / 小地图
  reticle.js          3D 准星：45° 交互旋转 / 攻击红化放大 / 停留进度环
  tension.js          紧张值系统：灯光压暗 / 色偏 / 暗角 / 心跳 / 抖动 / 拖影
  postfx.js           自研拖影后处理（WebGLRenderTarget 累积缓冲 + UI 分层渲染）
  save.js             进度存档读写（localStorage）
  ending.js           比赛结算与结局分支
  main.js             事件绑定 / 主循环 / 初始化入口
```

JS 全部是传统脚本（非 ES Module），按 index.html 中的顺序加载并共享全局作用域，
新增模块时注意把被依赖的定义放在前面。

## 加题

1. 在 `assets/problems/` 新建一个以题目 id 命名的文件（如 `P10001.js`）；
2. 内容为 `PROBLEM_DATA.push({ id, name, max, tl, ml, desc, starter: STARTER_TEMPLATE });`；
3. 在 `index.html` 中按同样格式补一行 `<script>` 引入。

## 主线：大战保安

### 保安

殴打监考老师会叫来保安，同时亮出 3 格血条。

- **名额**：保安总出场名额上限为 500 人（`GUARD_MAX_TOTAL`），耗尽后不再补充；
  击倒全部 500 人才能打开终局之门。
- **增援**：每击倒一名，门口补一批替补。每批 2 人，击倒 40 人后 3 人，120 人后 4 人，
  并均匀分布在玩家四周形成合围。
- **强度**：保安有 1 / 2 / 3 点耐久。多耐久的保安体型更大、略快，吃一拳只会被打退并
  僵直约 0.45 秒，不会倒下；击倒数越高，多耐久保安的比例越高（100 杀后出现 3 点耐久）。
  移速随击倒数上升，上限比初始高约 0.75。
- **行为**：远处斜向包抄（左右各半），近处直扑，互相保持间距；进入约 2.8m 后会短暂
  突进（约 2.6 倍速，有冷却）。
- **受击**：被保安碰到扣 1 格血（窗口闪红 + 提示），玩家侧 1 秒无敌，
  无论几个保安同时碰到都只掉一格；血量耗尽才被抓走。
- **出拳**：左键出拳，判定为准星前约 ±23° 的扇形、约 2.5m 范围，一拳可命中范围内
  全部保安；多耐久保安需要多次攻击。监考倒台之后，同学也进入可攻击范围。

### 保安通报

击倒 10 人之后，每次出拳击倒保安有 10% 概率（`GUARD_WARN_CHANCE`，每拳只掷一次）
弹出保安队通报，标题显示当前已击倒人数。语气随击倒数分四档升级：口头提醒（10–19）、
正式警告（20–49）、纪律处理（50–99）、最后通牒（100+）。

- 通报弹出的瞬间，整个世界放慢到 0.1x（考试计时不受影响），选项落地后恢复原速。
- **通报期间保安原地待命，无法伤人**；选择通报选项后还有约 1.5 秒保护期
  （`GUARD_ALERT_GRACE`），并把 1.8m 内的保安推到圈外（`GUARD_ALERT_CLEAR`）。
- 选项有三个：
  - **配合**：违抗计数清零，不加派保安，代价是 2 秒内不能出拳；
  - **嘴硬**（两条随机台词，效果相同）：违抗计数 +1（推高紧张值）并立刻叫来更多保安。
- 慢放覆盖整个世界：玩家移动、跳跃、受击间隔都按世界时钟同比例变慢，
  只有考试计时和镜头转向保持原速。

### 紧张值与成就

随着击倒数上升，紧张值（`js/tension.js`）会逐渐拉满：灯光压暗、雾色转暗红、
屏幕暗角随心跳收缩、对比度增强、镜头抖动加剧、全局拖影变长。
回座位静坐可以让紧张值部分回落，但贴身追来的保安不受影响。
击倒 10 / 20 / 50 / 100 名保安各有成就。

### 终局

打完全部 500 人不会直接结算：走廊尽头那扇门会打开，门口填满极强的白光并向房内投射，
伴随“门开了”警告弹窗；走向门口按 E “走出去”之后才进入主线终局「无人能挡」。
白光区域里准星与交互文字会自动反色以保证可读。

空格跳跃：视角随跳跃高度升降，空中不受桌面阻挡，落点卡进障碍会退回起跳点。

## 存档与计时

- 战斗中每 5 秒自动保存；击中保安、受伤、增援到场和评测完成也会保存。
  切换标签页或离开页面时会尝试立即保存，设置面板仍可手动保存。
- 存档包含击倒数、已出场名额、存活保安的位置/耐久/AI 冷却、待到场增援、
  玩家血量与位置、倒地同学、开门状态、处罚、代码和成绩。
  空中存档恢复到起跳点；弹窗、碎块和 NPC 临时对话不恢复。
- 读档保留增援的剩余等待时间，不扣离线时间；旧版存档仍可恢复答题记录，
  但旧版没有记录的战斗与处罚状态无法追溯。
- 考试计时使用未限幅的真实时间差：低帧率、后台节流不再延长考试。
  物理步长仍限幅，恢复页面时不会因大步长穿墙。实际用时独立累计，不受倍率修改影响。
- 所有结局都会取消未完成的评测/增援并清除本局存档；未完成评测不计入结算。

## 回归测试

无需安装依赖，使用 Node.js 18+：

```sh
node --test tests/*.test.cjs
```

测试覆盖评测保存与结算竞态、处罚和战斗读档、500 人名额与终局、考试计时及跳跃。
浏览器中的 WebGL 渲染和指针锁定仍需手动验收。
